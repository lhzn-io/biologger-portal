biologger-portal user guide
===========================

The biologger portal is the WHOI Marine Predators Group's hub for biologger deployments: a catalog of
deployments and their files, real validation of the tag data, and a viewer that draws each reconstructed
track over fused bathymetry.

Sections are added as each part ships:

- Deployments and the file grid
- Registering files and reading validation results
- The track viewer (2D map and 3D view)
- Collect, then ask your AI

Asking an AI
------------

The portal has no built-in chatbot. Collect the views you want to ask about, then copy the image and the
prompt into the assistant you already use. The prompt carries the same numbers the page shows, as text,
with method notes. Pasting sends those data to the assistant you choose.
