biologger-portal user guide
===========================

The biologger portal is the WHOI Marine Predators Group's hub for biologger deployments. It holds a
catalog of deployments and their files, validates the tag data, and draws each reconstructed track over
fused bathymetry in a viewer.

Asking an AI
------------

The portal has no built-in chatbot. Collect the views you want to ask about, then copy the image and the
prompt into the assistant you already use. The prompt gives the numbers that the page shows, as text,
with notes on the method. Pasting sends those data to the assistant you choose.
