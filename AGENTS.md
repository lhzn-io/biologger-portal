# Agent Onboarding & Contribution Guidelines

Maintainers of this repository leverage AI developer agents (such as Antigravity and Claude Code) to assist with UX implementation, code refactoring, and software development lifecycle (SDLC) tasks.

> [!NOTE]
> These developer agents are distinct from the portal's embedded AI chat interface. The embedded assistant interfaces with a bespoke, local `biologger-expert` agent running open-weights models on shared host compute without requiring external API keys.

This document serves as the onboarding guide and single source of truth for developer agent execution boundaries in this repository.

---

## Agent Execution Rules

*   **Git Commit and Push Approval (CRITICAL):** Before running `git commit` in this repository, you must present the complete proposed change set (diff) and the exact proposed commit message to the user for explicit review and feedback. Under no circumstances should a commit be made without explicit user review. Under no circumstances should an agent execute a remote `git push` without direct confirmation and explicit go-ahead from the user personally.

---

## Styling and Copywriting Rigor

To preserve academic and professional copy standards, all content generated by agents (including documentation, commits, and logs) must adhere to these principles:
1.  **No Spurious Emojis:** Do not use emojis in code comments, commit messages, READMEs, logs, or UI text.
2.  **No Em-Dashes ( - ):** Avoid the use of em-dashes. Structure sentences using clean parenthetical notation, colons, semicolons, or distinct sentences.
3.  **Grounded Language:** Keep tone engineered, quantitative, and objective (referencing hard numbers rather than generic adjectives).

---

## Repository Architecture & Tooling

*   **Repository Nesting:** All source code and static HTML is nested inside the `app/` folder. The root contains configuration files.
*   **Vite Execution Commands:**
    *   Development Server: `npm run dev` (runs `vite app`)
    *   Build Command: `npm run build` (runs `tsc -b && vite build app`)
    *   Preview Server: `npm run preview` (runs `vite preview app`)
*   **External Data Dependencies:** Raw biologger telemetry data is stored in `Projects/whoi-mpg/datasets` outside this repository. Do not commit or package CSV telemetry files within the portal repository.
